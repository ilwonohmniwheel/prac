연습문제 1. 타이머로 자동 정지하는 전동기 회로

동작 설명 보기
  1. MCCB를 올리면 GL(정지 표시)이 켜집니다.
  2. PB1을 누르면 릴레이 X가 동작하고 자기유지됩니다. 동시에 타이머 T와 MC가 동작해 전동기가 돌고, RL이 켜지며 GL이 꺼집니다.
  3. 타이머 설정 시간이 지나면 T의 한시 b접점이 열려 MC가 멈춥니다. 전동기가 정지하고 RL이 꺼지며 GL이 켜집니다.
  4. PB0을 누르면 X와 T가 풀려 처음 상태로 돌아갑니다.
  5. 과부하로 EOCR이 트립되면 제어회로 전체가 끊기고 YL이 켜집니다.

공개문제 형식을 본뜬 연습용 예제입니다. 핀 배치는 이 페이지의 내부결선도를 기준으로 하며, 실제 시험에서는 시험지에 주어진 내부결선도를 기준으로 확인하세요. 실제 작업에서는 조작 박스와 제어판 사이를 단자대와 배관으로 연결하지만, 여기서는 흐름이 잘 보이도록 직접 연결했습니다.
